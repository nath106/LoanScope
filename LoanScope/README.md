# LoanScope
## Requirements
- Node.hs 18 or newer

## Run it locally


1. Clone Repo
```
    git clone https://github.com/nath106/LoanScope
    cd <project-folder>
```
2. Install Dependencies:
```
    npm install
```
3. Start the dev server
```
    npm run dev
```
4. Open address in browser (ex. http://localhost:5177)
